# CROWN LCD INDIA — JAIN TELECOM

Static website made for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `crown-lcd-india`.
2. Upload `index.html` and `style.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` branch and `/ (root)`.
6. Save. GitHub will provide your website URL.
